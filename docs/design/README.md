# 设计资料归档

当前设计依据是[一期编辑器交互与视觉决策](../plans/phase-1-editor-visual-decisions.md)。原 uni-app 项目的历史设计稿不作为本项目验收依据。

已确认方向：中性浅灰白、深灰正文、克制蓝色强调，提供深灰背景的深色模式；链接文字颜色单独定义。具体色值、编辑模式、新建流程及样板门槛以决策文档为准。

本目录用于后续保存明确版本的视觉样板、设计说明及用户确认记录。每份资料注明日期、用途和状态（候选、已确认或已过时），并从文档索引链接。当前没有已完成的视觉样板或真机验收图。

设备原始截图、UI XML 和测试日志保存在仓库外；确需作为长期设计依据保存的整理后图片，应明确区分于运行产生的临时证据。

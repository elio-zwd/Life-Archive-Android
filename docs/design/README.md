# 设计资料归档

当前设计依据是[一期编辑器交互与视觉决策](../plans/phase-1-editor-visual-decisions.md)。原 uni-app 项目的历史设计稿不作为本项目验收依据。

2026-10-22 用户对当前 UI 不满意，决定先补齐一期功能与必要交互，整体配色/布局/视觉重做后置。现有页面仅为功能入口，不记录为最终视觉通过；当前功能和浏览器阅读验证见[功能交接](../engineering/phase-1-function-handoff.md)。

已确认方向：中性浅灰白、深灰正文、克制蓝色强调，提供深灰背景的深色模式；链接文字颜色单独定义。具体色值、编辑模式、新建流程及样板门槛以决策文档为准。

本目录用于保存明确版本的视觉样板、设计说明及用户确认记录。每份资料注明日期、用途和状态（候选、已确认或已过时），并从文档索引链接。2026-10-18 已增加可重复的 Robolectric 浅深色桌面渲染样板，使用同一份合成文档，见[编辑器交接](../engineering/editor-prototype-handoff.md)。渲染图存于仓库外；编辑图的键盘为占位，当前没有目标机验收图。

设备原始截图、UI XML 和测试日志保存在仓库外；确需作为长期设计依据保存的整理后图片，应明确区分于运行产生的临时证据。

笔记顶部点击文件名可重命名，更多菜单可移动笔记本和管理属性标签。属性编辑只覆盖可安全表达的简单 `tags` 字段，未知 YAML 字段保留；复杂 YAML 提示在源码中编辑。笔记本移动不把标签改为笔记本名称。阅读目录按正文标题生成，不使用文件名或 YAML title 合成正文标题。

首页计数行不再重复放置“标签”按钮，标签筛选统一从更多菜单或设置进入；选中标签后在计数摘要中显示当前条件，并可清除。

## 可操作范围与演示边界

- 浏览器中可以实际编辑、搜索、整理示例笔记，下载单篇 Markdown，预览并确认导入多个 Markdown 文件，备份恢复本样板数据。操作仅影响当前浏览器存储。
- 笔记、回收站、设置与阅读位置使用 `life-archive-home-a-demo-v2`，草稿另存于同前缀的 `-drafts` 键。初次打开可读取旧版 `v1` 示例数据；不会删除旧键。
- 保存先写浏览器存储，成功后才公开新状态。存储不可用或超出容量时不显示“已保存”；草稿未保护时提示保留页面并可从编辑页更多菜单导出当前原文。
- 浏览器样板备份为带格式标识和版本的专用 JSON，包含笔记、回收站、草稿、笔记本、设置与阅读位置；先校验，再确认替换。**它不兼容 Android 完整备份格式。** 导入文件大小限制只是样板约束，不表示 Android 的容量限制。
- 目录导入、笔记与附件 ZIP、系统附件导入、远程缓存管理只展示 Android 流程；不生成空 ZIP、不假报附件导入成功。阅读加速清理实际清理浏览器样板中的展示缓存，不影响笔记与草稿。
- 两种编辑入口共用同一个 textarea、选区及样板撤销历史。实验实时预览只演示入口和状态共用，仍使用源码与基础高亮，**不复刻 Compose 的显示变换、标记隐藏或长文索引机制**。
- HTML 阅读实现基础标题、列表、待办、引用、Callout、表格、行内格式和链接；Mermaid、块级公式保留原文并显示说明，行内公式、脚注、复杂嵌套和未知语法不作为完整兼容成果。图片／附件展示引用入口，不自动请求远程资源；笔记缩略图仍为内嵌示例封面。
- 重命名只维护能明确匹配的简单 WikiLink 与完整库内 Markdown 路径；跳过围栏／行内代码，同名歧义不猜测。复杂相对引用、块定位、事务一致性与 Android 正式解析逻辑不能由此样板证明。

日期：2026-10-28。状态：候选交互设计，等待用户评审；不是 Android 实现或真机验收记录。

入口：[交互设计稿 HTML](home-a-xiaomi14ultra.html)。保留 `1fbe468` 的首页视觉方向，单个 HTML 可直接在浏览器打开，也可通过本地 HTTP 服务预览；没有新增外部字体、图片或 JavaScript 网络依赖。

## 对齐依据与交互

笔记顶部点击文件名可重命名，更多菜单可移动笔记本和管理属性标签。属性编辑只覆盖可安全表达的简单 `tags` 字段，未知 YAML 字段保留；复杂 YAML 提示在源码中编辑。笔记本移动不把标签改为笔记本名称。阅读目录按正文标题生成，不使用文件名或 YAML title 合成正文标题。

首页计数行不再重复放置“标签”按钮，标签筛选统一从更多菜单或设置进入；选中标签后在计数摘要中显示当前条件，并可清除。

## 阅读页视觉（2026-10-29）

用户已确认风格图中的 A「浅灰蓝 · 极简文档」为默认方向，C「深灰 · 专注阅读」为对应深色模式。这是 2026-10-29 的阅读页记录；2026-10-30 的编辑页和独立主题选择见下一节。

- 阅读画布使用中性浅灰白／深灰和克制蓝色，正文采用清晰的无衬线字、舒展行距与统一段落间距。样式变量限定在阅读页，首页与编辑页不沿用这组新令牌。
- 导航栏缩小文件名并居中，目录改为有无障碍名称的图标入口；“笔记信息”收进阅读页更多菜单。
- 仅将 Markdown 开头的 H1 提到页头，依次展示正文标题、笔记本／更新时间／标签、封面和正文。保留原 H1 节点及定位 ID，目录和搜索仍能定位；没有开头 H1 时不从文件名合成正文标题。
- 原底部常驻按钮栏改为右下角“编辑”小浮钮。正文末尾预留滚动空间，短屏和大字号下可将末段滚动到浮钮上方；待办使用轻量方框，引用使用细蓝色侧线，不再使用大背景块。
- “周末计划”的山湖示例封面使用本次生成的清晰图像，以 WebP 内嵌到 HTML，不引入网络请求，也不修改原笔记 Markdown 或首页缩略图。其余笔记沿用已有示例数据；这不是附件导入或自动生成封面的功能。

浅深色、320 px 窄屏的实际 HTML 截图已在浏览器中核对，截图保存在仓库外；方向确认不等于小米 14 Ultra 真机验收。

## 编辑页 A 与文档主题（2026-10-30）

用户确认 A「浅灰蓝 · 极简写作」及压缩后的工具布局，沿用当前 HTML 更新，不新增另一个编辑入口或跳转文件。

- 文件名与保存状态收进同一顶栏，编辑正文使用连续画布。字符数与行列仍计算，但不再常驻占用一行；正文来源、300/800 ms 草稿与保存计时、输入选区和撤销历史沿用原交互。
- 列表／格式／插入均为互斥的单行图标面板，面板 52 px、按键 44 px，不靠缩小触摸目标压缩高度。窄屏可横向滑动，溢出时右端显示“查看更多工具”；普通点击仍作用于原正文选区。
- 长按工具按键约 500 ms 显示当前按键的中文名称，松手不触发命令；横向拖动、取消触摸、切面板或离开页面会取消提示。桌面悬停与键盘聚焦也可查看名称，按键保留中文无障碍名称。标题长按改为统一提示，级别选择从编辑页更多菜单进入；单击／双击加深／减浅继续保留。此处为最新样板决定，Android 原有长按选择尚未修改。
- 格式面板新增“清除行内格式”：处理完整选中的简单外层标记或选区紧邻的同类标记；复杂源码、跨行或无完整匹配时提示调整选区，保留原文。代码内容不进一步清洗。
- 阅读页和编辑页的更多菜单各有“主题”，共享 A 浅灰蓝、B 暖纸色、C 深石墨三套配色。选择保存在样板 `prefs.pageTheme`，刷新、切笔记及样板备份恢复时保留；首页的跟随系统／浅色／深色设置独立。旧数据或旧备份没有此字段时，按原首页外观选取 A／C 默认值，明确选择后不再跟随首页设置。未知主题值不通过备份校验，保存失败时不假报切换成功。
- 桌面默认提供不可输入的键盘布局示意，便于比较键盘展开后的正文高度；可从页面上方开关或编辑页更多菜单隐藏，收起键盘按钮也会隐藏它。触屏浏览器及短横屏不展示模拟键盘，输入使用浏览器／系统键盘；该示意不能证明百度输入法或 Android 键盘适配通过。
- 在 HTML URL 末尾添加 `#editor` 可直接打开第一篇现有示例笔记编辑，不创建或覆盖笔记。普通入口仍从首页进入阅读，再显式编辑。

这些更新只涉及 HTML 视觉与交互样板，没有修改 Android 页面或设备资料。

## 小米 14 Ultra 画布与交接截图（2026-10-30）

桌面默认以 432 × 960 固定逻辑画布预览，按可用窗口整体缩放，正文、工具栏及键盘示意不再因电脑窗口高度而重排。该画布严格为 9:20，与官方 1440 × 3200 竖屏规格一致；逻辑宽度是设计基准，未从目标手机读取当前 DPI 或 dp。

## 可操作范围与演示边界

- 浏览器中可以实际编辑、搜索、整理示例笔记，下载单篇 Markdown，预览并确认导入多个 Markdown 文件，备份恢复本样板数据。操作仅影响当前浏览器存储。
- 笔记、回收站、设置与阅读位置使用 `life-archive-home-a-demo-v2`，草稿另存于同前缀的 `-drafts` 键。初次打开可读取旧版 `v1` 示例数据；不会删除旧键。
- 保存先写浏览器存储，成功后才公开新状态。存储不可用或超出容量时不显示“已保存”；草稿未保护时提示保留页面并可从编辑页更多菜单导出当前原文。
- 浏览器样板备份为带格式标识和版本的专用 JSON，包含笔记、回收站、草稿、笔记本、设置与阅读位置；先校验，再确认替换。**它不兼容 Android 完整备份格式。** 导入文件大小限制只是样板约束，不表示 Android 的容量限制。
- 目录导入、笔记与附件 ZIP、系统附件导入、远程缓存管理只展示 Android 流程；不生成空 ZIP、不假报附件导入成功。阅读加速清理实际清理浏览器样板中的展示缓存，不影响笔记与草稿。
- 两种编辑入口共用同一个 textarea、选区及样板撤销历史。实验实时预览只演示入口和状态共用，仍使用源码与基础高亮，**不复刻 Compose 的显示变换、标记隐藏或长文索引机制**。
- HTML 阅读实现基础标题、列表、待办、引用、Callout、表格、行内格式和链接；Mermaid、块级公式保留原文并显示说明，行内公式、脚注、复杂嵌套和未知语法不作为完整兼容成果。图片／附件展示引用入口，不自动请求远程资源；笔记缩略图仍为内嵌示例封面。
- 重命名只维护能明确匹配的简单 WikiLink 与完整库内 Markdown 路径；跳过围栏／行内代码，同名歧义不猜测。复杂相对引用、块定位、事务一致性与 Android 正式解析逻辑不能由此样板证明。

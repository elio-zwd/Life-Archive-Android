## 2. 实现边界和接手入口

- `EditorRenderProjection` 是显示投影，不修改正文、选区、组合输入或撤销历史。受影响片段不超过 8 KiB 时先局部解析；巨型段落、代码块或大粘贴先保留映射样式，等待后台完整解析。超过 128 KiB 的文档沿用光标附近高亮窗口，未扩大为全篇富文本排版。
- `EditorViewModel` 的保存收集和解析任务独立；`retire()` 在保护正文后等待旧工作结束。恢复资料前同时结束列表模型及 app 持有的复制/创建任务。首页以新代次创建新 ViewModel，旧回调不负责恢复后的导航或正文。
- `ReaderRenderer.Content` 接收 `ReaderSnapshot`，`ReaderServices` 仍通过 Repository 取得链接、嵌入和资源。滚动回调不参与 snapshot 或 WebView 加载地址；缓存完成调用 `readerResourceUpdated`，不重建整页。错误页保留重试。
- `LibraryRepository.resolve` 增加 `LinkSyntax`，默认 WikiLink 以兼容已有调用。Markdown/HTML 按来源目录解析；以 `/` 开头的路径按库根解析；裸 Wiki 文件名的多个候选明确反馈歧义。不能据此宣称所有 Obsidian 文件和 HTML 方言均已验收。
- 多文件日志的 `rolledBack` 默认 false，兼容旧记录；状态数据库仍为 v2，不增加破坏性迁移。完整备份外层格式仍为 v1，缓存不进入备份。`BackupEngine.commit` 返回显式结果，异常/取消时仍由 StorageGate 中断恢复保护后续访问。
- 工具链和阅读依赖版本不变；未创建新模块，也未修改任何真实笔记库、手机或见域项目。

# 0.2.3 工具栏与回车续写交接

日期：2026-10-24。需求依据：[工具栏计划](../plans/phase-1-editor-toolbar.md)。在 0.2.2 上增加编辑操作，继续采用源码编辑＋完整阅读，实时预览为实验项；整体视觉重做后置。正文、草稿、备份及阅读加速缓存沿用原有机制，没有新增模块、依赖或状态迁移。

## 1. 使用说明

进入笔记后点击“编辑笔记”。底部依次为撤销、重做、标题、列表、格式、插入、收起键盘。中间区域窄屏可横向滚动，收起键盘按钮固定可见；列表、格式和插入面板互斥，各为两行横向滚动。

| 入口 | 使用方式 |
| --- | --- |
| 标题 | 单击加深，正文→H1→…→H6，H6 停住；双击只减一级，H1→正文。单击在系统双击判定窗口后生效。长按选择正文或 H1～H6；多级选区显示“混合”。可用无障碍自定义动作加深、减浅或选择级别。 |
| 列表 | 选无序、有序或待办进行转换，再选当前类型取消；缩进、减少缩进、勾选／取消作用于当前行或选中行。增加缩进前须有可作为父项的列表项。 |
| 格式 | 加粗、斜体、删除线、高亮、行内代码可切换。有选区处理选中文字，空光标插入成对标记，光标在已有同类格式内可取消。无法安全拆分的嵌套选区提示调整，不猜测删除。 |
| 链接 | 插入面板的“链接”填写地址；选中文字作为默认显示文字。HTTP(S)、邮件、电话地址可用。 |
| 双链 | 搜索并选择笔记，可填写显示别名。确认前重新读取目标、核对解析身份；特殊文件名无法用 WikiLink 表示时，勾选“使用 Markdown 链接”。 |
| 附件 | 系统选择器导入后插入嵌入引用。取消不改正文；返回时正文、光标或会话已变，保留已入库附件并显示“插入当前光标”，由用户明确选择。 |
| 模板 | 两列表格、可填语言的代码块、分隔线、六类 Callout、行内／块级公式、两节点 Mermaid、自动编号脚注。脚注引用与定义一次撤销。 |

多行标题逐行增减，选区结束于下一行行首时排除该行；空白选中行跳过，空白光标行可创建标题。Setext 标题转换为 ATX，保留标题文字及格式；多行 Setext 的软换行合为空格，整体转为一条 ATX 标题。多行格式处理避开标题、列表和引用容器标记。表格中的所选多行文字转为单元格换行并转义竖线；分隔线插入保留选中文字。

回车会续写非空列表、待办和引用；有序项按当前编号加一，新待办为未完成。空项回车退出一层。标题后的普通回车进入正文；YAML、代码和表格等受保护位置保持普通换行。多行粘贴与组合输入确认不触发续写。

中文候选词尚未确认、草稿尚未处理、会话只读或正在执行命令时，正文命令不可用。关闭对话框不修改正文；Activity 重建保留表单，进程重启后不重放旧插入。源码与实时预览共享正文、选区及原生撤销历史。

## 2. 实现入口与边界

- `core/document/.../EditingCommands.kt`、`InlineEditing.kt`、`MarkdownInsertion.kt` 计算原文补丁与 UTF-16 选区；命令解析可在后台执行。未修改区域不经过 Markdown 序列化。
- `MarkdownContinuation.kt` 仅扫描换行所需容器状态，不在普通字符输入时构建全文 AST。`EditorSession.continuation` 在公开 InputTransformation 的单次输入事务中应用续写。为使续写独立撤销，插入型续写连同前一个完整且不变的 Unicode 字符形成替换，不删除历史、不使用内部 API。
- `EditorSession` 核验会话、原文、选区和输入代次，一次应用命令；即使输入后撤销回原文，旧请求仍失效。空格式占位仅取消本会话刚创建且未变的占位，不把用户原有 `~~~~` 代码围栏误当删除线。
- `EditorToolbar.kt` 使用 combinedClickable 的一个手势入口判定标题单击／双击／长按，正文或选区变化取消待判定动作。工具栏不持有独立的正文格式状态。
- `EditorViewModel` 管理可取消的插入表单和带序号的链接查询；输入状态始终属于原来的 EditorSession。feature 通过 Repository 查询和解析链接，app 装配及承接系统选择器。
- `MarkdownModel.kt` 在原有显示投影中增加高亮范围，继续保护代码、属性、注释、公式和组合输入。自动保存与高亮准备继续独立运行，沿用 300 ms 草稿和 800 ms 正文计时。

模板是可编辑原文，不是可视化表格、公式或图表编辑器。引用处的语法修改遇到无法安全表达的结构会拒绝；不会从阅读结果重新生成正文。完整阅读及 32 MiB 内存／256 MiB 内部磁盘缓存的既有状态另见[阅读提速交接](phase-1-reader-performance-handoff.md)。

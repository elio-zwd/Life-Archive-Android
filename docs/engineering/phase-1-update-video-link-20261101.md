# 独立更新视频链接

日期：2026-11-01，按用户确认计划实现，当前范围见[视频摘记计划](../plans/phase-1-video-notes.md#独立更新视频链接)。保留 AI 填写 source 的提示词规则，以及四类完整内置文本不超过 1000 字符的约束。

## 入口与操作

- 首页粘贴预览／视频收录页点击“更新链接”，已有笔记从阅读／编辑更多菜单点击“更新链接”。只有主动点击更新或重新粘贴时读取剪贴板纯文字，URI 不强转文字，页面重建不重读。
- 共用对话框展示当前链接、分享内容和提取的网址，可编辑分享文字、重新粘贴。单链接自动选中，多链接需明确选择；空／非文字／无网址输入不能确认，取消不修改内容。
- 预览只修改待保存 Markdown，提示“链接已应用，保存笔记后生效”；已有笔记基于当前会话修改 source 并立即保存，磁盘提交成功才提示“链接已更新”，不切换阅读／编辑模式。

## 原文与保存边界

`core:document` 提供分享链接提取及 NoteSource 单字段读写。提取仅识别 HTTP／HTTPS，保留原始短链、尾随斜杠、查询参数、片段和百分号编码，不联网、不展开重定向、不判断视频是否存在。排除分享文案、口令和外围标点，多链接按原文顺序去重。

source 单行字符串安全替换／缺字段补充，无 YAML 时新增最小 frontmatter；JSON frontmatter 使用原文区间替换，复用并扩展既有 JSON 顶层成员定位。其他属性、注释、正文、BOM 和换行保留，重复 source、未闭合 YAML、块标量／锚点等无法安全定位的结构拒绝自动修改，提示源码编辑。

共用对话框及其展示状态属于设计系统，输入和保存状态分别由 notes／editor ViewModel 管理；无 feature 相互依赖，无新增模块或 Repository 接口。更新发生在当前编辑器会话，保留未保存正文、支持一步撤销，使用既有版本检查、草稿与串行保存协调器。待处理草稿、中文输入组合、命令执行、保存中或已知冲突时不提交。保存失败仍保留当前内容及分享输入，可重试；版本冲突按原有另存／草稿流程处理。正文仍为 Markdown 权威来源，备份格式不变。

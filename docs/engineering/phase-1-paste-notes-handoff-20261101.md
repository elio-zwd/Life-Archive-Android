## 使用方式与边界

首页可见“粘贴”按钮，点击后才读取剪贴板，展示自动文件名、标签和可修改的完整 Markdown，点“保存”创建并打开阅读。保留“更多”中的快速记录和视频摘记；视频“收录总结”使用相同解析、预览及创建流程，额外提供可选来源。回收站禁用首页粘贴。

初始文件名依次取 YAML title、一级标题、正文首个非空行前 40 字，最后回退到日期时间名；清理 Markdown 装饰并满足 Windows 名称和库内路径约束，重名添加数字后缀。已有正文与 YAML 不重排，未知属性保留；缺 YAML 才补 title 和空 tags，缺标签可直接保存。疑似未闭合 YAML 保留并提示。仅去掉确认包裹全文的单层 markdown／md 围栏，普通代码不拆。文件名推导仅发生在新建边界，不引入后续隐式同步。

取消预览不落盘，替换已有正文要确认，手动名称和来源保留；失败输入保留，存储忙碌时阻止重复创建。旋转重建保留预览，剪贴板不会随重建或阅读返回自动重读。未保存表单不承诺进程被终止后的恢复。

四类默认提示词在原任务结构之前加入统一规则：输出以 YAML frontmatter（title、tags）开头，再接正文标题；标题安全转义，AI 自行选择 2～4 个大类／主题标签，避免人名、案例、零散词和同义词堆叠。不携带库内标签，也不由 App 推断主题。

提炼的阅读规则直接包含在提示词里，外部 AI 无需访问本地路径：

- 普通知识使用段落和列表；步骤用有序列表，必要对比用表格。代码块仅用于真实代码、命令、配置和必要图示。
- **粗体**用于少量术语／关键词；`==高亮==` 用于少量核心定义、原理、因果和结论，保留读者继续标记的空间。
- 函数、API、变量、类型、文件名使用行内代码；一段一个重点，方便选中与继续编辑。
- 简单关系用文字，不滥用 Callout、Mermaid、装饰、多层嵌套，不强制安排练习或填写任务。
- 保留条件、数字、参数和例子，区分视频原意与补充解释，不把案例规范写成通用定律，不确定字幕明确标注，不编造来源。

用户自定义提示词不覆盖，需通过“恢复默认”采用新版；旧模板产出的普通文本仍能收录。继续使用十个模块与 NotesRepository.create，不增加权威状态或备份版本。

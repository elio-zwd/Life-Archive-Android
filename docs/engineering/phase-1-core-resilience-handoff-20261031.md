| 布局／尺寸缓存 | JSON `null` 导致属性访问失败；字符串尺寸原先可被隐式接受 | 校验对象及有限数值；非法条目按未命中处理 |

| 原生配置时序 | 在模块启动前注入配置，原实现仍使用旧修订打开 | 原生在方法尚未就绪时保留最后配置，模块用该配置开始首屏 |
| 加载入口 | 模块、导入依赖或必要经典脚本请求失败时缺少可恢复入口 | 独立启动脚本提供可见错误和整页重试，通知原生展示错误页 |
| 异步显示条件 | 排版期间改变主题／字号，原实现先存派生物再检查条件是否过期 | 在写入和展示之前核对会话与显示条件；缓存响应解析后再次检查会话 |

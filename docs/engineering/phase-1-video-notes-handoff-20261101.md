# 0.2.6 视频摘记实现与验证

日期：2026-11-01。一期完成后新增需求，版本 0.2.6／versionCode 8，保持 main。初次交付时没有提交、推送或连接手机；原一期开发及验证完成的结论保持历史含义。

## 使用方式

首页“更多 → 视频摘记”，两个页签可独立使用：

1. **复制提示词**：选择通用摘记、操作技巧、知识讲解或选择与避坑；复制当前内容到小红书点点。修改后点“保存修改”长期保留，复制本身不保存；“恢复默认”确认后只重置当前类。
2. **收录总结**：填写笔记名，主动点击“粘贴总结”或用系统菜单粘贴，按需填写来源。已有正文时确认替换。目标笔记本在进入时固定显示，没有选择则为根目录。
3. **保存并编辑**：创建成功后进入已有编辑器，返回助手时已收录表单清空，未保存的提示词编辑仍保留。保存失败或重名时留在表单，修改后可重试。

App 不接入 AI、不抓取视频、不接收外部系统分享；具体提示词初稿与确认范围见[视频摘记计划](../plans/phase-1-video-notes.md)。

## 实现与数据兼容

- 沿用十个模块，`feature:notes` 新增对 `core:preferences` 的允许依赖；app 只装配导航和公开能力，正文统一通过 NotesRepository 创建。
- `PreferencesRepository.setVideoPrompt(type, text)` 写入固定类型覆盖值，null 清除覆盖。内置文案留在笔记功能中，不写入用户覆盖值；最多四份，每份 16,000 个字符。
- 自定义提示词进入原 preferences 备份参与者，设置快照显式写 format=2；兼容 format=1 和省略默认版本字段的旧快照，旧备份恢复时清除现有覆盖、回到内置模板。设置文件体积上限 512 KiB，覆盖最大长度和 JSON 转义。外层备份 v1、notes format=3、状态库 v3 不变。
- 笔记名与正文标题／YAML 独立，正文原文不重排、不要求模板章节；可选来源原样追加在“## 来源”下，沿用正文 CRLF 或 LF 换行。来源不会被自动访问。
- ViewModel 保留旋转和切换 App 期间的表单及各类提示词编辑、替换／返回确认状态。未确认保存的表单不承诺在进程被终止后恢复。存储操作期间禁用重复动作，创建结果由导航消费后才清空表单。

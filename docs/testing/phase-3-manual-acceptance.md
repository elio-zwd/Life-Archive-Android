# 三期真机验收清单

目标：小米 14 Ultra、Windows 10 x64。电脑结果见[三期交接](../engineering/phase-3-sync-handoff.md)，不代替本表。

初始均为 `NOT_VERIFIED`。先用新建测试笔记本与测试附件验证，再同步正常资料；保留现有完整备份。覆盖安装保留数据，不清库、不卸载。

| 项目 | 操作与预期 | 状态 |
| --- | --- | --- |
| 覆盖安装 | 安装新版 APK，原笔记、主题、封面、阅读状态仍在 | NOT_VERIFIED |
| PC 初始化 | 新版 PC 初始化固定目录并生成配对码，不自动 Git 提交 | NOT_VERIFIED |
| 首次配对 | 同一局域网，使用实际网卡地址；错误／过期码有提示 | NOT_VERIFIED |
| 手机到电脑 | 中文笔记本、笔记、图片／PDF 可在 Obsidian 打开 | NOT_VERIFIED |
| 电脑到手机 | 新增和修改笔记及附件，手机同步后可读 | NOT_VERIFIED |
| 改名移动 | 双端分别操作，不重复笔记，手机封面、置顶、阅读位置保留 | NOT_VERIFIED |
| 冲突 | 验证手机版、电脑版、跳过；未选择的内容不丢失 | NOT_VERIFIED |
| 同名不同 ID | 先选择版本，落败版本可回收 | NOT_VERIFIED |
| 删除恢复 | 双端分别删除笔记及附件，另一端可恢复；恢复后再同步 | NOT_VERIFIED |
| 草稿保护 | 未解决草稿不被覆盖，处理后可重试 | NOT_VERIFIED |
| 断线重试 | 断网后重试，错误明确，不重复、不损坏已保存文件 | NOT_VERIFIED |
| 无变化 | 重复同步不重传文件内容 | NOT_VERIFIED |
| 配对重启 | 普通重启保留连接，撤销配对后须重新配对 | NOT_VERIFIED |
| AI 副本 | 每轮备份相关文件，补备份不覆盖首份，副本不进 Git 或手机 | NOT_VERIFIED |
| 完整恢复 | 恢复笔记、状态和同步回收站，随后重新配对核对 | NOT_VERIFIED |
| 网络和界面 | 大附件进度、滚动、键盘遮挡、界面重建体验可接受 | NOT_VERIFIED |

问题记录注明两端版本、系统／WebView、网络、操作顺序及截图／日志位置。截图、UI XML、完整日志存仓库外；日志不含凭据或正文。

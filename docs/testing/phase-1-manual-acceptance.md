## 日常使用与本轮 UI

- [ ] **新建与打开**：取消命名不产生笔记，重名不覆盖；命名成功后进入编辑并弹键盘；快速记录可用；已有笔记默认阅读且不自动弹键盘。文件名、正文标题、YAML title 各改各的。
- [ ] **首页组织与搜索**：文件名／正文中文搜索、笔记本＋标签组合、清除条件、五种排序、置顶和管理均正确；改条件时不闪现全部资料、不误打开其他笔记。
- [ ] **首页内容与长列表**：有图／无图、长名称、多标签、深目录、空结果都可读；摘要和属性标签真实，无图不造封面；末条和管理入口不被浮钮遮挡。约 500 篇上下滑动、长筛选选末项及返回位置无明显卡顿或错位。
- [ ] **三页视觉与主题**：首页浅深色、编辑／阅读 A 浅灰蓝／B 暖纸色／C 深石墨符合已认可设计；主题卡、目录和菜单正常。文档主题与首页外观独立，切笔记／重开 App 后记住选择，系统栏文字可见；大字号仍能操作。
- [ ] **真实键盘与中文输入**：候选词确认、中英切换、表情、粘贴、删除、拖选和撤销无吞字／光标乱跳；收起后点击正文能重新输入，光标所在段落及工具栏不被键盘挡住，无重复底部空白。
- [ ] **工具栏与回车**：标题单击加深、双击减浅，更多菜单可选级别；长按图标只提示中文、松手不执行，横滑可找到全部工具。列表／待办／引用回车续写，空项逐层退出；格式／插入后一次撤销正确。清除行内格式只处理安全的简单格式，复杂选区不误删。
- [ ] **保存与重开**：返回首页、切笔记、后台返回、重开 App 后原文一致；保存状态真实。用测试笔记检查 Debug 保存失败提示、草稿保留和重试；源码／阅读切换不丢改动。实验实时预览若使用，也核对共享正文与撤销。

## 文件、兼容和数据保护

- [ ] **重命名／移动／标签**：移动、改名及笔记本操作后原笔记和附件仍在，相关内部链接仍能找到目标；失败或重名不假报成功。属性标签管理不损坏未知 YAML，正文 #标签仍可搜索。
- [ ] **回收站**：删除后可恢复，路径冲突不会覆盖其他笔记；永久删除有明确确认；被其他笔记引用的共享附件仍可打开。
- [ ] **完整阅读**：使用“创建验收样例”及常用文档，检查表格、代码、公式、Mermaid、Callout 折叠、脚注、属性、双链别名、标题／块引用和笔记嵌入；目录及跨笔记跳转正确，没有多造正文标题或丢原文。
- [ ] **图片／媒体／PDF**：图片尺寸与本地引用正确，音视频可播放及定位，约 50 MiB PDF 可翻页／缩放，系统打开附件可用；重启后仍能读取。PDF 首屏占位不当成实际页已完成。
- [ ] **导入导出与 Obsidian 往返**：文件／目录导入可取消、冲突不覆盖；单篇 Markdown 和便携 ZIP 可导出。电脑 Obsidian 打开导出资料，再导回核对正文、未知 YAML、中文路径、链接及附件关系。
- [ ] **完整备份实际恢复**：备份后对照恢复出的笔记、图片／附件、笔记本、标签、置顶、回收站、草稿、阅读位置和设置／文档主题；重启可读，旧编辑页不会把恢复前内容写回。不能只检查“备份导出成功”。
- [ ] **离线与缓存**：默认手动加载远程内容，明确加载／自动缓存后的图片或网页可断网重读；失败刷新保留旧副本。清理阅读／远程缓存不删除笔记，重开可重新生成，不出现旧资料库的图表或元信息。

## 速度与长文

- [ ] **阅读和编辑体验**：50 KiB／1 MiB 测试文档首次打开、返回重开、重启后重开分别观察；高亮、连续回车、键盘唤起与滚动无崩溃／吞字／整篇闪动，阅读位置可恢复。公式／图表切换主题后正确，PDF 和媒体不被无关保存重置。
- [ ] **计划性能指标**：如需确认量化达标，由新 AI 协助在目标手机记录至少 20 次采样；500 篇列表／搜索 p95 ≤ 500 ms，冷启动可用列表 p95 ≤ 2 s；普通样例／50 KiB 阅读首次 p95 ≤ 1 s、命中重开 ≤ 500 ms，1 MiB 单列。不用模拟器布局或主观顺畅推算毫秒。

模拟器可按用户认可规格检查布局；真实手机的输入、系统交互与性能另记结果。设置等其他临时页面没有获准重做，能完成既有功能即可。AI、电脑同步及将实时预览改为默认不在本次清单。

每项可记录“已通过／有问题／本次未测”，附简短说明；用户已通过项以用户明确结论为准。对应历史入口见[输入修复](../engineering/phase-1-editor-input-handoff.md)、[阅读提速](../engineering/phase-1-reader-performance-handoff.md)、[完整功能矩阵](../engineering/phase-1-function-handoff.md)。

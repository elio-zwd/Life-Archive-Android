| 项目 | 验收操作与预期 | 状态 |
| --- | --- | --- |
| 启动与入口 | 冷启动进入 Life；切换菜单有 Life／见域／伙伴。首次打开伙伴可用，初始化失败能返回 Life | NOT_VERIFIED |
| 三域状态 | 分别留下未发输入和阅读位置，反复切换、后台返回和重建，状态保留，无重复生成 | NOT_VERIFIED |
| 公共 AI | 从伙伴导入 Key 后见域能看到同一列表，反向同样成立；伙伴切换模型不改见域用途；删除 Key 的影响范围明确 | NOT_VERIFIED |
| 对话 | 真实服务回应可读，失败／断网／限流明确提示；停止、显式重试和连续点击不重复追加消息 | NOT_VERIFIED |
| 记忆 | 手工添加和从消息选入，更正、删除后检查后续请求及重开结果；区分关系记忆和仍保留的原对话 | NOT_VERIFIED |
| 存储 | 保存档案、未发输入、消息和记忆后重启仍保留；生成中结束进程后明确显示中断，不自动重发 | NOT_VERIFIED |
| 域间隔离 | 使用合成备份恢复／清理见域后，公共配置／Key、宠物资料及 Life 笔记仍保留；不要覆盖真实资料验收 | NOT_VERIFIED |
| Life 回归 | 笔记保存、编辑阅读、同步和原独立备份按受影响流程定向检查 | NOT_VERIFIED |

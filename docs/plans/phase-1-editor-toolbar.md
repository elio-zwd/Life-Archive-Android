# 笔记工具栏增强与回车续写

日期：2026-10-24。目标版本：0.2.3。需求已确认；实现及检查结果另见[工具栏交接](../engineering/phase-1-toolbar-handoff.md)。本计划沿用临时视觉、源码编辑＋完整阅读，实时预览仍为实验项，不把电脑测试视为小米 14 Ultra 验收。

输入修复补充（2026-10-24，0.2.4）：按容器实际顺序处理列表／引用交错；`1. > 内容` 回车续为 `2. > `，空项只退出最内层。九位编号达到上限、嵌套过深或保护上下文无法安全确认时保留普通换行。正文修订与选区／焦点分离，复用快照与样式区间索引，回车使用会话检查点并最多补扫 8 KiB；完整高亮解析在初次准备后采用 200 ms 防抖，保存仍独立遵循 300/800 ms。高亮未就绪不卸载或阻塞输入控件。源码与实时预览均回归百度输入法常用提交协议，手机验收另记；实现及实际结果见[输入修复交接](../engineering/phase-1-editor-input-handoff.md)。

## 1. 操作约定

| 操作 | 规则 |
| --- | --- |
| 标题 | 单击正文→H1→…→H6，边界停住；双击反向，H1→正文。单击等待系统双击窗口，双击仅执行一次减级；长按选择正文或 H1～H6，无障碍提供对应动作。按钮显示当前级别或混合状态。 |
| 多行标题 | 按各行原级别增减，选区结束在下一行行首时排除下一行；跳过选区空行，空白光标行可创建标题。Setext 转 ATX，保留文字和内联原文。 |
| 列表 | 无序、有序、待办互转；同类型再次操作取消。提供缩进、减少缩进及统一勾选／取消，保留外层引用。首项不能缩进成无父项的代码块。 |
| 文字格式 | 加粗、斜体、删除线、高亮、行内代码切换。有选区作用于选中文字，无选区插入成对占位；光标在相同格式内部可取消。多行逐行处理，跳过空白与容器标记；部分取消保留选区外样式，不能安全拆分时提示调整选区。 |
| 常用插入 | 外部链接、搜索笔记生成双链、附件、引用、表格、代码块、分隔线及 Callout。链接默认显示选中文字。 |
| 进阶插入 | 行内／块级公式、Mermaid、脚注，生成 Markdown 模板；不增加公式、图表或表格可视化编辑器。 |

表格默认两列表头及两行正文。代码语言可选，空值为 text，围栏避开内容中的连续反引号。Callout 提供 NOTE、TIP、WARNING、DANGER、QUESTION、EXAMPLE。公式使用有效示例；Mermaid 为两节点流程图。脚注选择未占用的 `fnN`，引用与文末定义作为一个撤销事务。多行 Setext 转为单条 ATX 时软换行合为空格，保留文字和内联语法。

插入分隔线保留选中文字；多行文字放进表格时转为单元格换行并转义竖线。无法安全表示的 WikiLink 提供 Markdown 链接选项，不猜测另一个目标。

## 2. 回车与输入

- 非空列表项续写同类前缀。有序编号按当前值加一，不重排后文；新待办始终未完成。
- 引用继续当前层级，嵌套保留容器。空列表／引用项回车退出一层；普通标题换行进入正文。
- YAML、代码和表格等受保护位置不误续写。仅处理组合输入已结束、折叠光标的一处单换行增量；候选词确认、多行粘贴、批量替换保持原样。
- 使用现有公开 InputTransformation 在一次输入事务内续写；普通字符不触发同步全文解析。续写保留先前输入，单次撤销只撤销该次续写。

## 3. 状态与实现边界

- 主工具行：撤销、重做、标题、列表、格式、插入、收起键盘。三类面板互斥，展开为两行横向滚动；键盘收起按钮固定在右端。保留正文选区和焦点。
- `core:document` 计算原文区间修改及新选区；`EditorSession` 一次应用到同一 TextFieldState，不重建历史。源码和实时预览共享会话，显示投影支持高亮，保存流程独立运行。
- 标题使用 Compose 组合点击的单一手势入口。延迟动作绑定会话及选区，正文变化或输入、撤销、换笔记后失效。工具状态由正文和选区推导。
- 对话框及附件返回核验会话、插入位置和输入代次。取消不改正文，旧回执不写入较新正文；已入库附件可明确选择重新插入当前光标。对话框随 Activity 重建保留，进程恢复不重放。
- 笔记选择通过 Repository 查询、读取最新目标并验证解析身份。双链使用明确库内路径，Markdown 使用来源目录相对路径，处理中文、括号、特殊字符及同名目标。
- 组合输入、未处理草稿或会话不可编辑时禁用正文命令。保留 BOM、换行类型、未知 YAML 及未修改原文；不从显示结果反向生成正文。
- 不新增模块、依赖、数据库迁移或持久设置。保留 0.2.2 的首屏调度和 32/256 MiB 阅读缓存。

## 4. 验证与交付要求

命令及输入回归覆盖 H1～H6、双击互斥、多行和反向选区、Setext、嵌套格式、缩进、脚注冲突、特殊路径、一步撤销／重做、真实 InputConnection 组合协议、多行粘贴、过期请求、Activity 重建及 SOURCE／LIVE 保真。继续验证 50 KiB／1 MiB 文档及慢解析下 300 ms 草稿、800 ms 正文保存。

运行 `verifyPhaseOne`：架构、各模块测试、阅读脚本浏览器测试、七个 Android 模块 Debug Lint、App／仪器测试 APK、Release Kotlin 编译。交付 APK、说明、手机验收表；标题双击手感、输入法、键盘遮挡和滚动由用户在小米 14 Ultra 手动验收，未测项目记录 NOT_VERIFIED。

保持 main，保护已有未提交内容；0.2.4 按用户后续授权分类本地提交，不推送、不操作手机。0.2.3 当时按命令计算、交互接入、测试、文档分类本地提交的约定仅作历史记录。API 依据：[Compose 手势](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/tap-and-press)、[InputTransformation](https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/input/InputTransformation)。

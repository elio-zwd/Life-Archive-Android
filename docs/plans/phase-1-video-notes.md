# 一期补充：视频摘记助手

日期：2026-11-01。用户确认的一期完成后新增需求；原一期完成结论保留。实现与分层验证见[视频摘记交接](../engineering/phase-1-video-notes-handoff-20261101.md)。

## 目标与范围

流程：Life Archive 复制提示词 → 用户在小红书点点总结视频 → 复制结果 → 回到 App 粘贴、自动解析并预览 → 保存为普通笔记。2026-11-01 后续确认增加首页可见“粘贴”按钮，保留快速记录和视频摘记入口；实现及本轮验证见[粘贴建笔记交接](../engineering/phase-1-paste-notes-handoff-20261101.md)。

不接入 AI、不抓取视频、不增加 Android 系统分享接收，不扩展成通用模板管理或独立总结库。App 不读取视频，也不保证点点遵守提示词；实际效果用真实视频单独确认。

## 复制提示词

首页“更多 → 视频摘记”提供“复制提示词”和“收录总结”两个独立页签。

- 固定四类：通用摘记、操作技巧、知识讲解、选择与避坑。每类均可复制、编辑、保存及单独恢复默认；不增删或重命名模板。
- 内置文案与用户覆盖值分开，修改长期保留并纳入完整备份；恢复默认移除该类覆盖值。复制当前编辑内容不等于保存修改。
- 保存失败保留输入，复制成功或失败均明确反馈。每类提示词最多 16,000 个字符，空白内容不允许保存。
- 各类间切换保留未保存的编辑。恢复默认需确认；离开时如有未保存输入，确认放弃。

2026-11-01 实际使用反馈后更新：四类内置提示词均不超过 1000 字符（含统一规则、格式示例与本类要求），面向职场面试、简历、说话技巧、汇报、工作工具，以及养生、周末活动、生活技巧与美食做法。自定义提示词的既有 16,000 字符存储上限不变，已有覆盖值不自动替换。

四类共享规则：

> 将完整笔记放入一个用四个反引号包裹的 markdown 代码块，块外无说明，方便复制源码；代码块内部第一行是 YAML 的 `---`，title、tags、source、结束 `---` 分行，tags 固定为带双引号的行内列表。YAML 后空一行接 `# 正文标题`。标题通常 10～20 字，与一级标题一致，避开 Windows 文件名非法字符。App 已有逻辑可去掉外层包装；保存后的普通知识仍是正常 Markdown，不另放代码块。

四类均要求 YAML `source` 填当前视频已确认的原始或分享链接，保留完整 URL；无法获取时输出 `source: ""`，禁止猜测、拼接或填写示例网址，不在正文重复来源。App 不负责从视频推断链接，已有未知属性保留逻辑直接保存该字段。

AI 自行选择 2～4 个可复用的大类标签，优先 2 个，不凑数量，不堆叠同义／上下位标签。职业发展、沟通表达、工作效率、健康管理、休闲生活、饮食烹饪只是常见示例，不是固定清单或每篇必选项。

仅保留《Obsidian 课程辅助资料生成规则》的通用阅读约定：段落与列表、步骤有序、必要对比用完整表格，关键词适量加粗，核心结论少量高亮，一段一个重点，少用装饰与提示框；移除 API／函数／代码文件等代码课程专用要求。区分观点、依据与补充，不编造来源、经历、业绩、参数或活动信息，不把个人养生体验写成确定疗效。已有自定义覆盖值保留，用户可恢复默认采用新版。

| 类型 | 追加要求 |
| --- | --- |
| 通用摘记（964 字符） | 面试、简历、职场经验、养生及生活见闻；核心结论、关键要点、适用场景，不强套课程结构。 |
| 操作技巧（992 字符） | 简历修改、汇报准备、工作工具、生活技巧与美食做法；目标、准备与条件、操作步骤、注意事项，保留设置、用量、火候、时间及判断标准，缺失不补造。 |
| 知识讲解（994 字符） | 面试思路、说话技巧、汇报逻辑与健康生活知识；核心观点、为什么、具体例子、怎样应用、适用边界，沟通保留对象、场合、话术与表达思路。 |
| 选择与避坑（999 字符） | 求职策略、工作工具、周末活动、饮食及生活方案；选择目标、判断维度、方案差异、适合谁、常见坑，未提供费用／时间／地点不补造，无对比则只整理原则及避坑。 |

以上为可调整的试用初稿，不是强制导入格式。

## 收录总结

- 首页“粘贴”与视频“收录总结”共享解析和预览表单，展示自动文件名、识别标签及完整 Markdown；视频页保留可选来源。首页不经提示词页，回收站禁用粘贴入口。确认保存前不创建文件。
- 初始文件名依次取 YAML `title`、首个一级标题、首个非空正文行（前 40 字），否则用“粘贴记录-日期时间”；移除 Markdown 装饰、替换非法字符、处理 Windows 保留名及路径长度。创建时重名添加数字后缀，不覆盖旧笔记。预览名称可改，后续文件名、YAML title 与正文标题各自独立。
- 仅点击“粘贴总结”才读取剪贴板文字。已有正文时确认替换；空白或非文字剪贴板提示后保留表单，也可通过系统输入菜单手动粘贴。
- 正文不能为空白，不要求固定总结章节；已有 YAML、标签、未知属性与正文保留，不重排。缺 YAML 时补安全转义的 title 与 `tags: []`，App 不推测主题标签。疑似未闭合 YAML 时保留原文并提示，不再补第二份属性。只有全文为单层 markdown／md 围栏时移除外层，真实代码及内部围栏保留。
- 来源允许原始分享文字或链接，不自动访问或推断；非空白来源原样追加在正文末尾“## 来源”下。
- 目标笔记本固定为进入时的选择，没有选择则根目录。空白／非文字剪贴板不创建；取消预览不落盘；失败保留表单并允许重试，连续点击不会重复创建。
- 保存成功打开笔记阅读，返回时已收录表单清空，尚未保存的提示词编辑保留。
- ViewModel 保留切换 App 和旋转屏幕期间的输入；未确认保存的表单不承诺在进程被系统终止后恢复。返回时有未保存输入则确认放弃。

## 独立更新视频链接

用户确认 AI 链接可保留，并增加人工更正：粘贴预览页提供“更新链接”按钮，已有笔记在阅读／编辑更多菜单提供同名入口。点击后才读取剪贴板，展示当前 source、分享文字和识别结果；支持手动修改、重新粘贴，多个不同网址必须选择，未识别到网址不能提交。取消不改笔记。

从小红书、抖音等分享文字提取 HTTP／HTTPS 原始地址，不按平台设白名单，不联网展开短链，不由 AI 推断。完整路径、尾随斜杠、查询参数、片段保留，去掉外围分享文案、口令和包围标点。只更新 YAML source，不把分享文案或新链接追加到正文。

预览确认只修改待保存 Markdown，提示“链接已应用，保存笔记后生效”；已有笔记通过当前编辑器会话做一次可撤销修改，保留未保存正文和阅读／编辑模式，磁盘提交确认后提示“链接已更新”。空／非文字剪贴板、无法安全修改的 YAML、草稿待处理、中文输入组合、保存中及版本冲突均明确反馈；失败保留输入，不误报成功。

source 存在则替换、缺少则补充；没有 YAML 时新增仅含 source 的 frontmatter，安全转义并保留未知字段、注释、正文、BOM 和换行。支持普通单行标量及现有 JSON frontmatter；重复 source、未闭合 YAML、块标量／锚点等不安全结构拒绝自动修改。没有新增模块、数据库字段、Repository 接口或备份版本。[实现与验证](../engineering/phase-1-update-video-link-20261101.md)单独记录。

## 数据、备份与验证

沿用现有模块和公开 Repository。四类提示词覆盖值属于用户设置；preferences 快照 format=2 兼容 format=1 和省略版本号的历史快照，旧备份恢复后使用默认模板。设置快照单文件上限从 64 KiB 调整为 512 KiB，覆盖四份最大长度提示词经 JSON 转义后的体积；notes 与外层备份格式不变。

电脑验证覆盖持久化、逐类恢复默认、完整备份及旧备份、粘贴确认、原文保真、冲突失败、重复点击和 Activity 重建；执行架构检查及一期构建回归。点点四类真实视频总结效果、手机剪贴板、实际输入法、后台切换与视觉体验另行验收，不以电脑结果代替。

# 一期补充：视频摘记助手

日期：2026-11-01。用户确认的一期完成后新增需求；原一期完成结论保留。实现与分层验证见[视频摘记交接](../engineering/phase-1-video-notes-handoff-20261101.md)。

## 目标与范围

流程：Life Archive 复制提示词 → 用户在小红书点点总结视频 → 复制结果 → 回到 App 收录并补来源 → 保存为普通笔记。

不接入 AI、不抓取视频、不增加 Android 系统分享接收，不扩展成通用模板管理或独立总结库。App 不读取视频，也不保证点点遵守提示词；实际效果用真实视频单独确认。

## 复制提示词

首页“更多 → 视频摘记”提供“复制提示词”和“收录总结”两个独立页签。

- 固定四类：通用摘记、操作技巧、知识讲解、选择与避坑。每类均可复制、编辑、保存及单独恢复默认；不增删或重命名模板。
- 内置文案与用户覆盖值分开，修改长期保留并纳入完整备份；恢复默认移除该类覆盖值。复制当前编辑内容不等于保存修改。
- 保存失败保留输入，复制成功或失败均明确反馈。每类提示词最多 16,000 个字符，空白内容不允许保存。
- 各类间切换保留未保存的编辑。恢复默认需确认；离开时如有未保存输入，确认放弃。

四类共享初稿：

> 请将这个视频整理为方便以后查阅的中文 Markdown 笔记，直接输出正文，不要用代码块包裹全文。保留关键条件、数字、例子和注意事项，避免笼统概括。明确区分作者观点和视频提供的依据，没有提到的信息不要补造。不要虚构来源链接，不必生成 YAML 或标签。无内容的章节省略。

| 类型 | 追加要求 |
| --- | --- |
| 通用摘记 | 按“核心结论、关键要点、适用场景”组织，保留有助于理解的例子。 |
| 操作技巧 | 按“解决什么问题、准备与条件、操作步骤、注意事项”组织，步骤按执行顺序排列，保留关键参数。 |
| 知识讲解 | 按“核心概念、原理解释、具体例子、适用边界”组织，说明概念之间的关系。 |
| 选择与避坑 | 按“选择目标、比较维度、各方案优缺点、适合谁、常见坑”组织，明确推荐依据；视频没有比较的内容不要补造。 |

以上为可调整的试用初稿，不是强制导入格式。

## 收录总结

- 提供笔记名、正文、可选来源三个输入；笔记名是文件名，不含 `.md`，不从正文标题或 YAML 推导、同步。
- 仅点击“粘贴总结”才读取剪贴板文字。已有正文时确认替换；空白或非文字剪贴板提示后保留表单，也可通过系统输入菜单手动粘贴。
- 正文不能为空白，但不解析或校验总结章节；普通文本、Markdown 及其他排版均可收录，保留输入原文。
- 来源允许原始分享文字或链接，不自动访问或推断；非空白来源原样追加在正文末尾“## 来源”下。
- 目标笔记本固定为进入助手时的选择，没有选择则根目录。沿用名称及冲突规则，同名不覆盖；失败保留表单并允许重试，连续点击不会重复创建。
- 保存成功打开现有编辑器，返回助手时已收录表单清空，尚未保存的提示词编辑保留。
- ViewModel 保留切换 App 和旋转屏幕期间的输入；未确认保存的表单不承诺在进程被系统终止后恢复。返回时有未保存输入则确认放弃。

## 数据、备份与验证

沿用现有模块和公开 Repository。四类提示词覆盖值属于用户设置；preferences 快照 format=2 兼容 format=1 和省略版本号的历史快照，旧备份恢复后使用默认模板。设置快照单文件上限从 64 KiB 调整为 512 KiB，覆盖四份最大长度提示词经 JSON 转义后的体积；notes 与外层备份格式不变。

电脑验证覆盖持久化、逐类恢复默认、完整备份及旧备份、粘贴确认、原文保真、冲突失败、重复点击和 Activity 重建；执行架构检查及一期构建回归。点点四类真实视频总结效果、手机剪贴板、实际输入法、后台切换与视觉体验另行验收，不以电脑结果代替。
